# 📊 Tamil Nadu Election Analytics Dashboard (2021 vs 2026)

## Overview

This project was developed as part of the Codebasics Resume Project Challenge.

The dashboard analyzes and compares Tamil Nadu Assembly Election data between 2021 and 2026 using Power BI. The goal is to transform complex electoral datasets into meaningful insights through interactive visualizations and data storytelling.

---

## 🎯 Project Objectives

* Compare election performance between 2021 and 2026
* Analyze party-wise vote share trends
* Identify regional dominance patterns
* Explore constituency-level candidate performance
* Create an interactive and user-friendly dashboard

---

## 🛠 Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization

---

## 📈 Dashboard Features

### KPI Overview

* Total Constituencies: 267
* Total Votes: 96 Million
* Total Parties: 166
* Total Candidates: 7,514
* Highest Votes: 220K
* Average Votes: 11.26K

### Interactive Filters

* Election Year
* Region
* Party
* Constituency

### Visualizations

* Party Performance Overview
* Party Vote Share Analysis
* 2021 vs 2026 Vote Comparison
* Top Performing Candidates
* Key Insights Panel

---

## 🔍 Key Insights

* DMK maintained a dominant electoral lead in 2026.
* BJP showed measurable growth compared to 2021.
* Several constituencies witnessed closely contested elections.
* Regional voting patterns vary significantly across Tamil Nadu.
